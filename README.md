# 🌙 Moon Magic

✨ A dreamy little moon that changes its phases every time you click it!

Moon Magic is a beginner-friendly interactive web project built using **HTML, CSS, and JavaScript**. Explore all eight moon phases with a simple click and enjoy a dreamy night-sky design.

## 🌷 Features

* 🌑 **8 Moon Phases:** Explore all eight phases of the moon.
* 🖱️ **Interactive Moon:** Click the moon to change its phase.
* 🔄 **Continuous Cycle:** The moon returns to the beginning after the final phase.
* 💜 **Dreamy UI:** Enjoy a beautiful purple night-sky background.
* ✨ **Smooth Effects:** Hover animations make the moon feel interactive.
* 📱 **Simple Layout:** A clean, centered interface.

## 🛠️ Built With

* **HTML5:** Creates the structure of the webpage.
* **CSS3:** Adds styling, colors, and animations.
* **JavaScript:** Controls the moon phases and click events.

## 🌙 Moon Phases Included

1. 🌑 New Moon
2. 🌒 Waxing Crescent
3. 🌓 First Quarter
4. 🌔 Waxing Gibbous
5. 🌕 Full Moon
6. 🌖 Waning Gibbous
7. 🌗 Last Quarter
8. 🌘 Waning Crescent

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser.
4. Click the moon or the **Next Phase** button.
5. Watch the moon cycle through its phases! 🌙
